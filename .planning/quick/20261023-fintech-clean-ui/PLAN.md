# Quick Task: Fintech Clean UI Redesign (Inspired by @dailyflutterui_2001)

## Objective
Transform the AI Image Text Editor UI into a ultra-clean, modern interface inspired by the reference mobile UI:
1. **Floating Capsule Dock**: A sleek floating bottom navigation pill with a high-contrast active capsule (`[ 🏠 Canvas ] [ 📑 Layers ] [ ⚙️ Properties ]`).
2. **Quick Actions Row**: Rounded container with circular icon buttons (`[ 🔍 Detect Text ] [ 🔤 Add Text ] [ 🪄 Inpaint ] [ ⇄ Compare ]`).
3. **Sleek Header**: Refined typography, status pills, circular action icons (Undo, Redo, Zoom), and high-contrast action buttons.
4. **Card-Style Layer Stack**: Layer items and floating selected layer cards redesigned with rounded corners, subtle gradient badges, and clean spacing.
5. **Modern Design System**: Polished surface colors (`#0f121d`, `#141824`, `#1e2538`), pill badges, and crisp micro-animations.

## Tasks
- [ ] Task 1: Update mobile bottom navigation in `App.tsx` to the exact floating capsule dock with high-contrast active pill.
- [ ] Task 2: Add quick-action pill row for canvas actions (OCR Detect, Add Text, Inpaint, Compare).
- [ ] Task 3: Redesign `Header.tsx` to align with the modern clean header style.
- [ ] Task 4: Polish `LayersPanel.tsx` and `PropertiesPanel.tsx` card aesthetics.
- [ ] Task 5: Verify build, run test suite, and ensure mobile responsiveness.
